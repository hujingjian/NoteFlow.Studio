
# 一、项目定位（给AI的精准描述）
**项目名称**：自媒体剪辑知识库智能体（个人桌面版）
**技术栈**：
- C# .NET 8（WPF桌面应用）
- CefSharp（内嵌浏览器，抓取抖音/自媒体视频，版本126.2.180）
- FFmpeg（自动下载视频、提取音频、提取文案）
- Whisper（本地语音转文字）
- Ollama + Qwen 本地大模型（回答、总结、提炼）
- 本地向量数据库（RAG检索）
- MySQL（结构化数据存储）
- RAG 架构（解决大模型幻觉、答案不准、收藏夹吃灰）

**核心目标**：
把你收藏的**剪辑、剪映、AE、动画效果、素材选择**类视频，自动变成**可检索、可精准问答**的私有知识库。
你问：“怎么做出人物抖动震动效果？”
AI **只从你收藏的视频里提取答案**，100%准确、不编造。

# 二、功能模块完整细化（可直接分阶段开发）
我拆成 **6 大模块、19 个子功能**，AI 能按顺序开发。

## 模块1：WPF主程序 + 内嵌浏览器（CefSharp）
1. **WPF 主界面**
   - 浏览器面板（内嵌抖音）
   - 任务栏：下载、提取文案、生成知识库、问答
   - 状态显示、日志输出
2. **CefSharp 浏览器自动化**
   - 打开抖音收藏页/任意视频页
   - 自动识别视频URL
   - 自动获取视频标题、描述、作者
3. **手动 + 自动触发**
   - 一键抓取当前视频
   - 批量抓取收藏夹所有视频
4. **视频地址解析**
   - 解析抖音真实视频地址（无水印）

## 模块2：视频自动下载与管理
1. **FFmpeg 视频下载**
   - 下载无水印视频到本地
   - 自动按分类保存
2. **文件管理**
   - 自动命名：标题_作者_UID.mp4
   - 记录存储路径、大小、下载时间
3. **下载队列、断点续传**

## 模块3：视频文案提取（核心）
1. **提取音频**（FFmpeg）
2. **本地语音转文字**（Whisper）
3. **生成字幕文件 .srt / .txt**
4. **文案清洗**：去除语气词、重复、无意义片段
5. **保存原始文案 + 清洗后文案**

## 模块4：AI 内容提炼（Ollama + Qwen）
1. **调用本地 Qwen 大模型**
2. 生成 5 类结构化内容：
   - 视频主题
   - 核心知识点（1-10条）
   - 操作步骤（剪辑/剪映/AE 步骤）
   - 关键词标签
   - 难度等级、适用场景
3. **输出标准 JSON 结构**，方便入库

## 模块5：RAG 向量知识库 + 本地向量库
1. **文本向量化**
2. **本地向量数据库存储**
3. **相似度检索**
   - 输入问题 → 检索最相关的知识点
   - 返回Top5最相关的视频文案片段
4. **RAG 提示词构建**
   - 只使用本地知识库回答
   - 禁止编造、禁止幻觉
   - 标明来源：哪条视频、哪个时间点

## 模块6：MySQL 结构化存储
1. 视频信息表
2. 文案原始表
3. 知识点提炼表
4. 向量索引表
5. 问答日志表

## 模块7：AI 问答界面（最终功能）
1. 输入问题
2. 本地检索向量库
3. Ollama Qwen 根据检索内容回答
4. 展示答案 + 来源视频
5. 可直接打开对应视频
