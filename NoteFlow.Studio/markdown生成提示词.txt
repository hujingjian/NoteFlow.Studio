# 截图插入规则（非常重要）

你必须严格遵守：

1. 截图必须插入到最接近的时间段
2. 不允许把截图统一放到文末
3. 截图要出现在对应内容附近
4. 截图说明必须结合：

   * OCR字幕
   * 当前主题
   * 上下文
5. 只保留重要截图
6. 重复画面不要重复插入
7. Markdown 图片格式必须为：

![时间](图片路径)

例如：
